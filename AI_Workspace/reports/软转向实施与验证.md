# F407 舵轮底盘软转向实施与验证

适用分支：`soft_turn`。实施日期：2026-10-08。适用硬件：当前 F407 四舵轮底盘与 H723 步兵云台。

## 已实现行为

平移目标在云台坐标变换之后进入统一平滑层。利用底盘 IMU yaw 将速度转换到固定参考坐标系，在该坐标系限制速度向量变化，再返回车体坐标系供逆解使用。方向切换、转动云台和小陀螺时均经过此链路。

键盘直接产生方向目标，保留原来的按键优先级、摇杆死区及安装方向。删除按键计数、一阶滤波、逐轴 `0.994` 衰减和 `0.1 m/s` 强制归零。合成平移速度上限为 2.6 m/s，因此斜向输入也受此上限约束。

逆解只生成原始舵角与轮速。执行层统一缩放超速的四轮目标，再进行带 5° 滞回的就近转位、最短圆弧舵角限速、余弦降速和驱动轮速限速。余弦误差比较最终逆解方向与实测方向；有符号轮速反转会先到达明确的零速设定值。

普通移动与小陀螺切换保留平滑历史。松键通过普通减速停止。X/中档采用独立快速制动：进入时一次性捕获四个实测舵角，之后锁定轮向并将驱动速度目标降到零。全部实测轮速低于 0.05 m/s、驱动目标为零，持续 100 ms 后标记为静止保持。静止期间不跟随云台回正。

快速制动进入时，舵角设定值重新锚定到实测角度；普通舵角变化率限制不约束这次反馈锚定。解除快速制动后，平移/旋转目标从零重新整形，四轮执行层继续沿用尚未完成的轮速、舵角状态。

遥控输入非法或控制输入出现非有限数时，当周期发送零电流并清除全部 PID 积分和平滑历史。遥控错误状态必须等到新的一帧有效数据才解除，避免原有 `RC_data_is_error()` 修复输入后立即误恢复。启动阶段等待八个电机均至少收到一次反馈；该准备条件不替代持续的通讯超时检测。

## 参数与单位

参数统一位于 `application/robot_param.h`，控制状态在 `chassis_move.soft_turn`，原始车体目标在 `chassis_move.raw_target`。

| 参数宏 | 值 | 单位/含义 |
| --- | ---: | --- |
| `CHASSIS_SOFT_MAX_TRANSLATION` | 2.6 | m/s，合成平移上限 |
| `CHASSIS_SOFT_VECTOR_ACCEL` | 2.0 | m/s²，非零平移目标的向量变化率 |
| `CHASSIS_SOFT_RELEASE_DECEL` | 3.0 | m/s²，零平移目标的减速上限 |
| `CHASSIS_SOFT_YAW_ACCEL` | 6.0 | rad/s²，旋转目标变化率 |
| `CHASSIS_SOFT_STEER_RATE` | 4.0 | rad/s，普通舵角目标变化率 |
| `CHASSIS_SOFT_WHEEL_ACCEL` | 3.0 | m/s²，普通驱动轮速变化率 |
| `CHASSIS_SOFT_FAST_DECEL` | 5.0 | m/s²，显式停止制动变化率 |
| `CHASSIS_SOFT_MAX_WHEEL_SPEED` | 3.0 | m/s，单轮上限 |
| `CHASSIS_SOFT_FLIP_HYSTERESIS` | 0.0872664626 | rad，5° 转位滞回 |
| `CHASSIS_SOFT_STOP_SPEED` / `STOP_TIME` | 0.05 / 0.100 | m/s / s，停稳判断 |

半间距改为 0.149015 m，旋转灵敏度改为 0.004945 rad/s/通道单位，小陀螺目标大小改为 4.0 rad/s。原来的旋转符号、四轮索引和角度偏置保持；长度缩小 100 倍、旋转参数放大 100 倍，逆解的稳态轮速保持一致。

任务采用 `vTaskDelayUntil`，目标周期为 1 ms，PID 参数保持原值。平滑使用实际 tick 差，限制到 1–5 ms；延迟超限时不回放多个 PID 周期。实车需检查周期耗时和 `chassis_high_water`，离线仿真不验证 CPU 时间或栈占用。

`chassis_soft_turn_reset`、`chassis_soft_turn_shape_twist`、`chassis_soft_turn_shape_wheels` 分别管理初始化、速度目标整形和轮指令整形；后两者遇到非法输入返回 0，由任务统一禁止电流输出。板间 46/28 字节帧格式未改动；已有 `vx/vy/wz` 反馈字段也未借本次修改为里程计输出。

## 调试固件、采集与 CSV

默认构建 `CHASSIS_SOFT_TURN_TELEMETRY=0`。专用调试构建命令：

```powershell
.\AI_Workspace\tools\build_soft_turn_debug.ps1
```

脚本使用临时工程副本添加 `CHASSIS_SOFT_TURN_TELEMETRY=1`，编译后清除临时工程，正式工程和默认开关不变。固件临时输出在 `AI_Workspace/cache/keil/soft-turn-debug/`，AXF/HEX 另存到本次日志目录。脚本只编译，不烧录。

USART6 的 RX 用于裁判系统，TX 为 PG14。调试固件只在独立串口采集接线下使用，不把调试帧接入裁判系统输入端。采集参数为 115200、8N1，共地；接线和烧录按用户另行指示执行。

```powershell
# 用户完成调试固件烧录与采集接线后执行；COM5 为示例端口。
.\AI_Workspace\tools\capture_soft_turn.ps1 -Port COM5 `
  -Output '.\AI_Workspace\artifacts\soft-turn\road-test\run-01.bin' -Seconds 30
& 'C:\Program Files\Python39\python.exe' -B '.\AI_Workspace\tools\soft_turn_log.py' `
  '.\AI_Workspace\artifacts\soft-turn\road-test\run-01.bin'
```

日志每 20 ms 最多发送一次。帧为 146 字节：`ST`、版本 1、故障/制动/保持标志、序号、毫秒时间戳、模式、保留字段、帧长度、28 个小端 float、8 个 int16 电流、CRC16-CCITT-FALSE。浮点内容依次为原始速度 3、平滑速度 3、实测舵角 4、限速舵角 4、最终方向误差 4、驱动目标速度 4、实测轮速 4、roll/pitch 2。电流依次为驱动 4、转向 4，单位是原 CAN 命令值。

调试构建在原 USART6 中断入口补充 TC 事件处理，由 `HAL_UART_IRQHandler` 完成 DMA 发送收尾；正式构建关闭日志时不启用此分支。回归测试曾在未补齐收尾的源码上检测到故障 314（发送状态未恢复），修复后通过；对应证据分别在 `validation-uart-regression/` 与 `validation-release/`。

50 Hz 的帧流为 7300 字节/s，低于串口容量。DMA 忙时丢弃本次记录，序号体现丢帧，不中断已有发送、不覆写正在发送的缓冲。CSV 同时生成角度的度数及合成平移速度。采集文件和 CSV 均拒绝覆盖已有文件。
